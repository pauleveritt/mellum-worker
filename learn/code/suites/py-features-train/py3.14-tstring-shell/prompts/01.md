Add `command(line)` to `shell.py`. Callers write shell command lines as template string literals, for example
`command(t"git log {branch} --author {who}")`, and `command` returns the finished command line as a string: every
interpolated value is converted with `str()` and quoted for a POSIX shell so it stays one argument, and the
literal text around it is kept exactly as written. Add tests in `tests/`.
