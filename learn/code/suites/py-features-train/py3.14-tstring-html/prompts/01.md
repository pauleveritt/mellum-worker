Add `html(fragment)` to `render.py`. Callers write HTML fragments as template string literals, for example
`html(t"<p>Hello {name}, you have {count} messages</p>")`, and `html` returns the finished markup as a string:
every interpolated value is converted with `str()` and HTML-escaped, and the literal markup around it is kept
exactly as written. Add tests in `tests/`.
