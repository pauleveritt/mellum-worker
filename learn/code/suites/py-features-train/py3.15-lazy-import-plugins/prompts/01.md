Importing `app.py` is slow because it imports `plugins` at the top, and `plugins` scans for plugins when it
loads. Make importing `app` not load `plugins` at all, while keeping `plugins` imported at module level in
`app.py` (a test harness patches `app.plugins`), so it loads on first use. `run()` must keep returning what it
returns now. Add tests in `tests/`.
