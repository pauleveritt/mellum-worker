Implement `retry` in `retry.py` (the signature is already there; `fetcher.load` uses it). It calls `fn()` up
to `attempts` times and returns the first result. After a failure that is an instance of `retry_on` it waits
`base_delay * factor ** n` via the injected `sleep` (0.1, 0.2, 0.4, ... by default) before the next try. There
is no wait after the final attempt: the last exception is re-raised. Any other exception propagates at once.
