`load_config(defaults_path, user_path=None, overrides=None)` in `config.py` layers `data/defaults.json`,
the user file (`data/user.json`) and an overrides dict, but a user file that sets only `db.port` wipes the
rest of `db`. Nested dicts must merge deeply at any depth; lists and other values replace. A user file that
does not exist is skipped. `merge` must not change the dicts passed to it. Add tests in `tests/`.
