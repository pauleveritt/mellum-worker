Add two options to the `inventory.py` command: `--limit N` shows at most N items (after sorting), and
`--format json` prints the items as a JSON list of `{"name": ..., "qty": ...}` objects instead of the
text table (`--format text` stays the default). The existing `path` argument and `--sort` must keep
working, alone and combined with the new options. Try it with `uv run python inventory.py data/items.csv`.
Add tests in `tests/`.
