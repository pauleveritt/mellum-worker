Implement `summarize(path, top=3)` in `logstats.py` for access logs in the format of `data/access.log`.
It returns `{"status": {code: count}, "top_paths": [(path, count), ...]}`: status codes are ints, and
`top_paths` holds the `top` most requested paths, most requests first, ties in alphabetical order.
The query string is not part of the path (`/api/items?page=2` counts as `/api/items`).
`uv run python logstats.py data/access.log` should print a sensible summary. Add tests in `tests/`.
