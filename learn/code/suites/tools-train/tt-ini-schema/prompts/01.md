`load(path, schema=SCHEMA)` in `loader.py` returns every INI value as a string. Use the types in `schema.py`
to convert them: `int`; `bool` from true/false, yes/no, on/off or 1/0 in any case (anything else raises
`ValueError`); `list` from comma-separated items with surrounding spaces and empty items dropped. Keys the
schema does not mention stay strings. Try `uv run python loader.py data/settings.ini`. Add tests in `tests/`.
