Implement `EventBus` in `events.py` (used by `audit.py`). `subscribe(event, handler)` registers a handler;
`unsubscribe(event, handler)` removes it (a no-op if it is not subscribed); `publish(event, payload=None)`
calls every handler for that event with the payload, in subscription order, and returns how many were called.
Handlers may unsubscribe themselves or others while a publish is running: that publish must still call every
handler that was subscribed when it began, with no skips or errors.
