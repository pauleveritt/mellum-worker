`parse_record` silently returns None for malformed lines, which hides bad data. Make it raise a new
`RecordError` (a `ValueError` subclass, defined next to `parse_record`) with a message that says what is
wrong. The bulk importer should keep going past bad lines: catch `RecordError` there, skip the line and
record its 1-based line number in the result's `errors`. Other callers should see the error.
