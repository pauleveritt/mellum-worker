`safe_write(base_dir, relative, text)` in `storage.py` must never write outside `base_dir`. Raise
`ValueError` (and write nothing) when the target would end up outside it, whether through `..`, an
absolute path, or a symlink inside `base_dir` that points elsewhere. Paths that stay inside are fine,
even with `..` in them (`a/../b.txt`), and missing parent directories are created. Add tests in `tests/`.
