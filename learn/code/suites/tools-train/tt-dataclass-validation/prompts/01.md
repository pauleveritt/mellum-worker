`ServerConfig.from_dict` in `config.py` accepts anything. Make it validate the dict against the field types:
raise a new `ConfigError` (a subclass of `ValueError`, defined in `config.py`) whose message names the field
when a required field is missing, a value has the wrong type (`port` must be a real int, `tags` a list of
strings), or the dict has an unknown key. Missing optional fields still take their defaults.
