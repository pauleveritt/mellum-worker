`wordfreq.py PATH [N]` prints the N most frequent words in a file, but its counts are wrong: run it on
`data/sample.txt` to see. Words must be counted ignoring case and punctuation (a word is a run of letters
and digits; an apostrophe inside a word, as in "don't", is kept), printed in lowercase as `word count`,
most frequent first, with ties in alphabetical order. Fix `count_words` and add tests in `tests/`.
