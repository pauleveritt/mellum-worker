Add `sql(query)` to `db.py`. Callers write queries as template string literals, for example
`sql(t"SELECT * FROM users WHERE name = {name} AND age > {age}")`, and `sql` returns a pair: the query text with
each interpolated value replaced by a `?` placeholder, and a list of the values in order. Literal text is kept
exactly. Values must never be pasted into the query text. Add tests in `tests/`.
