Add `pack(path)` and `unpack(path)` to `archive.py`. `pack` compresses a file with Zstandard, writes it next
to the original as `<name>.zst`, and returns the new path; `unpack` reverses it, writing the original name back
and returning that path. Use only the standard library: this project has no third-party dependencies and must
not gain any. Add tests in `tests/`.
