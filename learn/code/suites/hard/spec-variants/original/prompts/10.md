# Phase 7 — Visits report

`GET /visits` takes `from`, `to` (inclusive ISO dates), `min_minutes` (default
0) and `limit` (default 10). Group the `visits` table by agent for visits in
range with at least `min_minutes`; return `{"visits": [{"agent", "count",
"total_minutes", "average_minutes"}]}`, sorted by total minutes descending
then agent name ascending, and limited. Counts and totals are integers,
averages are floats.
