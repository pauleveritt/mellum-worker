# What This Is

This Learning Center teaches you how to run a small coding model locally behind Pi, and fix what goes wrong, with evidence. It is built for developers on macOS, Linux, or Windows who know a terminal and Python or Node.

![Paul and Andre at a table, one with a laptop and one with a notebook, the small robot between them](../assets/illustrations/about.webp){ .illustration }

It grew out of [mellum-worker](https://github.com/pauleveritt/mellum-worker), a project that measured the "Mellum as a bounded coding worker" recipe using a ladder of evals recorded in `evals/`. Every finding here comes from those runs or from [Andre van Zuydam](https://github.com/andrevanzuydam)'s pull requests.

This is [a collaboration between Paul and Andre](../credits.md). It is not the worker's manual; for that, see the [README on GitHub](https://github.com/andrevanzuydam/mellum-worker/blob/main/README.md).
