Build a small FastAPI app in `app.py`.

1. Add `GET /health`, which returns the JSON `{"status": "ok"}`. Give `app.py`
   an `if __name__ == "__main__":` block that serves the app with uvicorn on
   port 8000.
2. Run the app with `python app.py`, then check it live: save the output of
   `curl -s http://127.0.0.1:8000/health` to `health.txt`.
3. Then add `GET /items`, which returns the JSON list
   `[{"id": 1, "name": "apple"}, {"id": 2, "name": "pear"}]`, and
   `GET /items/{id}`, which returns that one item, or status 404 with
   `{"detail": "not found"}` for an id that does not exist.

Add tests for all three routes in `tests/test_app.py`, and run them.
