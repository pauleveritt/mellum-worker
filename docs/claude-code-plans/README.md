# Claude Code plan-mode captures

Plans written in Claude Code's plan mode while working this repo, kept here so
they travel with the code instead of living only in `~/.claude/plans/`.

These are **not** SDD plans. The spec-driven plans — the ones with `phase` /
`cycle` / `lifecycle` front matter, under the document caps — live in
[`../superpowers/plans/`](../superpowers/plans/) and close into
[`../superpowers/plans/archive/`](../superpowers/plans/archive/). A capture here
is the raw plan the agent and the developer agreed before a task; it records what
was intended, nothing more, and no cap or front-matter rule governs it.

Files are named `YYYY-MM-DD-<topic>.md` by the date the plan was agreed.
