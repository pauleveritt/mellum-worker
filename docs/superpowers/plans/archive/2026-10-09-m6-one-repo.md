# M.6 One Repo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the ladder, its fixtures and its readable records from mellum-mlx into this repo so the ladder measures this checkout, and archive raw evidence as release assets.

**Architecture:** A snapshot copy (via `git archive` at a pinned mellum-mlx commit) into `ladder/` (a uv project, stdlib + pytest) and `evals/`. The ladder's worker files resolve from `REPO_ROOT` (this checkout); the delegated agent file is rendered from `templates/pi/`. Raw traces become one deterministic tarball per phase, hashed in `evals/PROVENANCE.md`, uploaded by Paul.

**Tech Stack:** Python 3.14 (uv, pytest), Node 24 (`node --test`), Pi 1.0.2, oMLX on `127.0.0.1:8001`.

**Spec:** `docs/superpowers/specs/2026-10-09-m6-one-repo-design.md`

- Source: `/Users/pauleveritt/projects/pauleveritt/mellum-mlx` at commit `4b0f7e58a5ac0b10bfe678cce465c378d70161b1`. Copy with `git -C <mlx> archive 4b0f7e5 <paths>` so only tracked files at that commit arrive. Never edit, commit to, or delete anything in mellum-mlx.

- `ladder/` Python: `requires-python = ">=3.14"`, no runtime dependencies, dev group `pytest>=9.1.1`.

- Work happens on branch `m6-one-repo` in a worktree (superpowers:using-git-worktrees), after Task 1 lands on `main`.

## Review Focus

1. **The user's run log.** A ladder mode run must not append to `~/.pi/agent/mellum-mode-runs.jsonl`; the child env sets `MELLUM_MODE_RUNS` inside the scratch dir (Task 3).
2. **Double-loaded Mode.** The operator profile has the installed `mellum-worker` package; mode runs must drop it from the mirror so the extension loads once, from `-e` (Task 3).
3. **Running from the wrong directory.** All worker paths derive from `__file__`, so `python -m ladder.run_ladder` from `ladder/` and probe/sandbox from anywhere resolve the same files (Task 3 tests assert absolute paths that exist).
4. **Re-running the archiver.** Building a phase tarball twice gives the same SHA-256, and adding the README link twice adds it once (Task 4).
5. **Moved notes' relative links.** `](ladder/...)` in notes moved to `docs/superpowers/research/` must become `](../../ladder/...)`, or they dangle (Task 5 guard test checks every relative link in moved notes resolves).

## Deviations from the spec (flag in review)

- `archive_raw` lives in the package (`ladder/ladder/archive_raw.py`, run as `python -m ladder.archive_raw`) instead of `ladder/scripts/`, so its tests import it like the rest.
- `--out` stays required (a default name would collide across phases); examples use `--out ../evals/<name>`.
- The mellum-mlx guard test checks two things instead of one allowlist: no `github.com/pauleveritt/mellum-mlx` URL outside history files, and no bare mention in live files; phase records under `evals/` are history.
