## What would falsify this

Missing/multiple tagged instructions, changed user briefs, system-role drift,
source/runtime drift, or failed containment invalidate delivery/collection
claims. Hidden failures or stalls weaken the combination as a lead. Backend
accounting must reconcile; unresolved gaps remain explicit.

## Risks

Three repetitions do not establish reliability. Four hidden checks are narrower
than whole-phase acceptance. Compaction payloads can bypass the agent recorder;
independent server timing counters are a supplement, not retroactively captured
API usage. The 16,384-token response ceiling shares each slot's context.
